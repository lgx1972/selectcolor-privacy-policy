彩虹配色隐私政策

欢迎使用“彩虹配色”。我们非常重视你的个人信息和隐私保护。

生效时间：2026-08-10

欢迎使用“彩虹配色”。我们非常重视你的个人信息和隐私保护。本应用主要提供配色浏览、图片取色、扑克牌色卡、 配色收藏、保存图片和系统分享等功能。为说明这些功能如何处理数据，特制定本隐私政策。

一、我们处理的信息范围

本应用不会要求你注册账号，也不默认收集姓名、手机号、身份证号等直接身份信息。

在你使用具体功能时，应用可能处理以下信息：

  1. 图片选择信息
    当你主动使用“从相册选择图片”或“拍照取色”功能时，系统会通过 HarmonyOS 提供的图片选择器或相机能力返回你选中的图片资源，用于本地分析图片颜色。
  2. 本地配色与收藏数据
    当你使用配色收藏、扑克牌风格、风格排序、页面状态恢复等功能时，应用会在设备本地存储必要的数据，包括配色名称、颜色值、卡片顺序、收藏记录和部分页面偏好设置。
  3. 图片导出与系统分享文件
    当你主动执行“保存到相册”或“系统分享”时，应用会在设备缓存目录生成待导出的图片文件，并按你的操作写入系统相册或交由系统分享面板发送。
  4. 震动反馈
    当你长按拖拽色卡时，应用会调用设备震动能力提供交互反馈。

二、我们如何使用这些信息

我们处理上述信息仅用于以下目的：

  1. 完成图片取色、拍照取色和颜色分析。
  2. 保存你收藏的配色方案和界面偏好。
  3. 生成色卡快照并保存到系统相册。
  4. 通过系统分享面板分享色卡图片。
  5. 提供拖拽排序时的震动反馈。

我们不会将你的图片内容、配色收藏或本地偏好上传到开发者自建服务器。

三、我们使用的系统能力与权限

当前版本涉及的主要系统能力如下：

  1. 相册选择器：用于你主动选择图片进行取色分析。
  2. 相机能力：用于你主动拍照后取色分析。
  3. 系统相册写入能力：用于你主动将色卡图片保存到系统相册。
  4. 系统分享能力：用于你主动分享色卡图片。
  5. 振动权限 `ohos.permission.VIBRATE`：用于长按拖拽色卡时提供震动反馈。

四、数据存储与保留

  1. 配色收藏、扑克牌风格数据和部分页面偏好会保存在你的设备本地数据库或本地偏好存储中。
  2. 分享或保存时生成的图片文件会先写入本地缓存目录，再根据你的操作写入系统相册或交由系统分享能力处理。
  3. 你卸载应用后，本地应用数据通常会随应用一起删除；系统相册中已保存的图片是否保留，以系统实际行为为准。

五、第三方共享说明

  1. 本应用不向第三方 SDK 主动提供你的个人信息。
  2. 当你主动使用系统分享功能时，相关图片文件会由 HarmonyOS 系统分享面板交给你选择的目标应用，该过程受目标应用及系统机制约束。

六、你的权利

你可以通过以下方式管理相关数据：

  1. 不使用图片选择、拍照、保存到相册或分享功能。
  2. 在系统设置中管理相关系统授权。
  3. 删除应用内收藏配色或卸载应用。
  4. 删除系统相册中由本应用保存的图片。

七、未成年人保护

若你是未成年人，建议在监护人陪同下阅读本政策，并在监护人同意后使用相关功能。

八、隐私政策更新

当应用功能或数据处理方式发生变化时，我们可能更新本政策。更新后的版本将随应用版本或项目文档一并发布。
